# Proyecto KUBIX ELECTRóNICA DIGITAL 1

Este proyecto consiste en el diseño e implementación de un sistema inspirado en la consola  Game Boy con 4 pantallas de 64x64 Leds utilizando una FPGA, integrando módulos de control, comunicación y gestión de periféricos para permitir el funcionamiento coordinado del hardware.

La **documentación completa del proyecto**, incluyendo su descripción, diagramas y detalles de diseño, se encuentra en el archivo [`README.md`](render/README.md), ubicado en la carpeta `Render`.
